# Project2
## Description
A multithreaded bank simulation written in C using
POSIX threads and semaphores.

## Requirements
- 3 teller threads
- 50 customer threads
- Door capacity: 2 customers
- Safe capacity: 2 tellers
- Manager capacity: 1 teller

## Compilation
gcc -Wall -Wextra -pthread simulation.c -o simulation

## Execution
./project2
